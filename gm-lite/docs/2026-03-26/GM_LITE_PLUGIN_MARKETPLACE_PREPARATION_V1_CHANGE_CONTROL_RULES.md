# GM LITE Plugin Marketplace Preparation v1 Change Control Rules

## 允许改动
- marketplace 元数据与文档准备件
- icon / changelog / listing 说明
- 与 submission readiness 直接相关的最小补齐

## 禁止改动
- 真正发布动作
- 越界到 marketplace judgment / release execution
- 借 preparation 轮大改功能
- 篡改既有 local release 证据

## 变更原则
- 先补齐“能不能提交”的准备项
- 再做最后的放行判断
