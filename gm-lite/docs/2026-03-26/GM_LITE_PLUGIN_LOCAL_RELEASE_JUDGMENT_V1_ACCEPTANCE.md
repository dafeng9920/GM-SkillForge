# GM LITE Plugin Local Release Judgment v1 Acceptance

## 必须满足
1. local-use release 标准有明确结论
2. blocker / non-blocker 有明确分层
3. 已安装入口、sidebar、命令、最小使用体验至少一轮 judgment
4. 有最终 local release decision
5. `RJ1-RJ4` execution / review / compliance 三件套齐全

## 可接受结论
- `PASS`
- `PASS with documented gaps`
- `REQUIRES_CHANGES`
- `FAIL`

## 不可接受结论
- 没有区分 blocker 与普通瑕疵
- 用开发加载态代替安装包态 judgment
- 将本地自用 judgment 混同为公开发布 judgment
