# GM LITE Plugin Local Release Re Judgment v1 Boundary Rules

## In Scope
- 基于 hardening 后结果的本地长期自用 re-judgment
- blocker / non-blocker 重判
- 安装态入口、sidebar、命令、恢复链的重新判断
- 新的 local release decision

## Out Of Scope
- 插件市场正式发布
- 跨平台与跨机器验证
- 新一轮大规模实现
- 完整产品化 UI 改造

## 红线
- 不把 re-judgment 轮变成实现轮
- 不把本地长期自用判断混同为 marketplace readiness
- 不忽略 hardening 后仍残留的真实问题
