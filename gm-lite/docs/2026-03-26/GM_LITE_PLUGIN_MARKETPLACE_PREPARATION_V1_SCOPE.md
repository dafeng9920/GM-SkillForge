# GM LITE Plugin Marketplace Preparation v1 Scope

## 模块目标
- 把 `GM-LITE` 插件从“本地长期自用已通过”推进到“具备插件市场准备度”
- 补齐 marketplace preparation 所需的元数据、素材、说明和边界

## 本轮唯一目标
1. 补齐 marketplace 所需基础元数据与清单
2. 补齐 README / changelog / icon / listing 素材边界
3. 补齐 marketplace preparation 的已知 gap / exclusion / risk
4. 给下一轮 marketplace judgment / release execution 提供放行前提

## 完成定义
- marketplace preparation 至少完成一轮
- 有准备态证据
- 有 blocker / non-blocker 区分
- 有进入 release judgment 的条件判断
- `MP1-MP4` 三件套齐全
