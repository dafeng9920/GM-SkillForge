# GM LITE Plugin Marketplace Readiness Hardening v1 Boundary Rules

## In Scope
- LICENSE 文件
- CHANGELOG.md
- package.json metadata 推荐字段补齐
- 最小 listing assets 与说明
- publisher 验证前置条件说明

## Out Of Scope
- 真正 marketplace 发布动作
- publisher 账号实际购买/结算/提交
- 大规模功能开发
- 公开营销动作

## 红线
- 不把 hardening 轮扩成 release execution
- 不伪造 screenshots / listing 证据
- 不用本地证据替代 marketplace 平台侧真实验证
