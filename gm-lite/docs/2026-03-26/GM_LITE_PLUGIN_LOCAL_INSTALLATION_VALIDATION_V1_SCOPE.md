# GM LITE Plugin Local Installation Validation v1 Scope

## 模块目标
- 验证 `GM-LITE` 插件壳是否已经具备本地安装、启动、最小可用的条件
- 把“插件壳 seed”推进到“本地安装可用”验证层

## 本轮唯一目标
1. 验证本地安装路径与宿主条件
2. 验证插件安装后能否启动
3. 验证最小面板与最小动作是否可用
4. 验证安装态下的 send / receive / writeback / observability 是否仍成立

## 完成定义
- 至少一轮本地安装验证完成
- 有安装态证据
- 有缺口、风险、下一刀判断
- `PV1-PV4` 三件套齐全
