1. 安装态入口/Sidebar 稳定性至少一轮补强验证
2. 命令与状态反馈补强至少一轮验证

4. 有 hardening 后剩余 gap 判断
5. `LH1-LH4` execution / review / compliance 三件套齐全

## 可接受结论

- `PASS with documented gaps`
