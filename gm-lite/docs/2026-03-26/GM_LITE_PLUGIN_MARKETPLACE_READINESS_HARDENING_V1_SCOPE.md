# GM LITE Plugin Marketplace Readiness Hardening v1 Scope

## 模块目标
- 直接补齐 `MP1-MP4` 打出来的 marketplace blocker
- 把 `GM-LITE` 插件从“marketplace preparation = REQUIRES_CHANGES”推进到“更接近可放行判断”

## 本轮唯一目标
1. 补齐 LICENSE / CHANGELOG / metadata 推荐字段
2. 补齐 listing 所需最小资产（screenshots / banner / 文案边界）
3. 明确 publisher 验证前置条件
4. 为下一轮 marketplace judgment 提供更干净的准备态

## 完成定义
- 至少一轮 readiness hardening 完成
- 关键 blocker 被实际补齐或被压缩到最少
- 有剩余 gap 和下一轮 judgment 方向
- `MH1-MH4` 三件套齐全
