# GM LITE Plugin Marketplace Preparation v1 Boundary Rules

## In Scope
- publisher / manifest / metadata completeness
- README / changelog / icon / screenshots / listing 文案准备度
- marketplace packaging 合规边界
- 已知 blocker / non-blocker / exclusion / risk 记录

## Out Of Scope
- 真正 marketplace 发布动作
- 公开上架放行
- 广告推广或营销动作
- 大规模产品功能扩展
- 将本轮扩成 release execution

## 红线
- 不把 preparation 误判成“已可上架”
- 不跳过最终 marketplace judgment
- 不为过 preparation 而篡改既有证据
