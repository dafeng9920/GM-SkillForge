# GM LITE Blockage Recovery Runtime Minimal Implementation v1 Acceptance

## 通过条件
1. 有最小 blockage detection runtime
2. 有最小 recovery / resume runtime
3. 有 escalation / memo / remediation / resumed 的证据链
4. tri-split 在自动流转下仍然保留
5. `BR1-BR4` 的 execution / review / compliance 三件套齐全

## 不通过条件
- blockage / recovery 仍只有 schema 没有 runtime
- 只能挂起不能恢复
- 恢复链没有物证或无状态推进
- 自动化直接压塌 tri-split
