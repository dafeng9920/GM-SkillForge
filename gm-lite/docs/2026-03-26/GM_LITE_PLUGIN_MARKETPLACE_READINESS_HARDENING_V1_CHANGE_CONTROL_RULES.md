# GM LITE Plugin Marketplace Readiness Hardening v1 Change Control Rules

## 允许改动
- `vscode-extension/package.json` 元数据补齐
- `LICENSE`
- `CHANGELOG.md`
- README / listing 文案最小补齐
- screenshots / banner 等最小资产占位与说明

## 禁止改动
- 真正 marketplace 发布
- 越界到 release execution
- 大规模功能重构
- 伪造平台侧验证结果

## 变更原则
- 先补齐可提交前提
- 再进入 marketplace judgment
