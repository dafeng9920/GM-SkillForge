# GM LITE Plugin Local Usability And Stability Hardening v1 Boundary Rules

## In Scope
- 安装态活动栏入口与 sidebar 的持续可见/可进性
- 命令触发后的状态反馈补强
- 重复打开、重装后再进入、最小恢复路径补强
- 为本地长期使用 judgment 服务的最小稳定性增强

## Out Of Scope
- 插件市场发布
- 跨平台兼容
- 完整产品化 UI
- 大范围功能扩展
- 将本轮扩成新功能开发轮

## 红线
- 不破坏当前已稳定的 `.vsix` 本地安装包态
- 不把 hardening 轮扩成产品重做
- 不回避 `RJ3 / RJ4` 已打出的稳定性问题
