# GM LITE Plugin VSIX Packaging And Local Installation v1 Scope

## 模块目标
- 把 `GM-LITE` 插件从“开发加载态已稳”推进到“`.vsix` 打包 + 本地安装包态可验证”
- 验证插件是否能以接近真实分发形态在本机安装、启用、显示入口并保持最小可用

## 本轮唯一目标
1. 形成 `.vsix` 打包路径与宿主前提
2. 形成本地安装包安装 / 卸载 / 重装的最小验证路径
3. 验证安装包态下活动栏图标、sidebar、命令入口仍成立
4. 输出 packaging 缺口、风险和 release direction

## 完成定义
- 至少一份 `.vsix` 产物生成或明确 blocker
- 至少一轮本地安装包态验证完成
- 有安装态证据
- 有已知缺口、排除项、下一刀判断
- `VX1-VX4` 三件套齐全
