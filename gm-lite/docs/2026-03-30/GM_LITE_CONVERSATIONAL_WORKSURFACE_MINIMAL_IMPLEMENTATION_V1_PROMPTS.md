# GM-LITE Conversational Worksurface Minimal Implementation V1 Prompts

## Operator Framing

The target is not "make a prettier panel."

The target is:

- open `GM-LITE`
- talk to it
- see what it is doing
- see what files / writebacks it produced
- click the next useful action

## Working Rule

Prefer a small but real conversational worksurface over a broad but scattered command set.
