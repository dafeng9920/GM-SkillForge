# GM-LITE Main Workbench Elevation And Collaborative Console V1 Scope

## Module

- `gm_lite_main_workbench_elevation_and_collaborative_console_v1`

## Intent

Promote `GM-Lite Console` from an Explorer-side view into the plugin's true main workbench, then harden it into a more capable collaborative control surface.

## Primary Goal

Make `GM-Lite` feel like one clear working destination:

- open plugin
- land in a real main workbench
- talk to it
- see outputs and file destinations
- get next-action guidance
- continue real project work without being buried in Explorer sections

## In Scope

- elevate console into a standalone main panel / editor-style workbench surface
- keep Explorer views as secondary/supporting entry points
- strengthen collaborative console behavior on top of the elevated workbench
- improve real-project continuity, next-action guidance, and operator relief

## Out of Scope

- replacing SkillForge governance
- broad runtime-center expansion
- marketplace / publish work
- upstream vault / keep implementation
- full general-purpose chat assistant parity

## Success Test

This cut succeeds only if `GM-Lite` stops feeling like "one more Explorer section" and starts feeling like a real primary workbench that supports ongoing project collaboration.
