# GM_LITE_PLUGIN_ENTRY_STABILIZATION_AND_SIDEBAR_DEFAULT_INTERACTION_V1_SCOPE

## Objective

Stabilize the `GM-LITE` plugin entry so the plugin is easier to summon and use as a real interactive sidebar, instead of relying on command-palette-only access.

## In Scope

- stabilize activity bar entry visibility
- make `GM-Lite: Open Sidebar` reliably open the interactive sidebar
- align default entry behavior with sidebar-first usage
- reduce mismatch between installed behavior and expected UI behavior

## Out of Scope

- heavy dashboard redesign
- new bridge/runtime features
- superpowers integration
- marketplace work
