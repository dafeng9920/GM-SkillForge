# GM_LITE_PLUGIN_REAL_USABILITY_LOOP_V1_SCOPE

## Objective

Push the `GM-LITE` plugin from "minimal bridge exists" into "real usable loop" by making the operator able to trigger, observe, and follow a task-linked bridge cycle with less manual effort.

## In Scope

- task-linked bridge invocation from plugin surface
- run-to-task visibility
- callback/writeback return visibility from plugin surface
- minimal repeated-use loop for operator
- keep operator confirmation and visible state boundaries

## Out of Scope

- heavy automation
- full executor runtime
- superpowers-lite implementation
- governance / permit logic
- large dashboard UI
