## Change Control

During this line:

- interaction layout may still evolve
- object-to-surface mapping may be refined
- button/action arrangement may still be adjusted

During this line it is forbidden to:

- create heavy free-form UI state disconnected from bus objects
- add scheduler-like automation
- collapse governance and interaction into one layer
