# GM_LITE_EXECUTION_BRIDGE_AND_CONTRACT_PREPARATION_V1_SCOPE

## Objective

Absorb the validated three-layer positioning into a formal `GM-LITE` mainline and define the minimal bridge/contract preparation layer between:

- `gm-lite` as shared task reality
- `superpowers`-class execution methodology layer
- `SkillForge` as audit/permit layer

## In Scope

- three-layer positioning freeze
- `GM Execution Bridge` responsibility boundary
- `ExecutionLaunchContract` minimal contract definition
- `.gm_exec` execution workspace layout
- standard return objects:
  - `Receipt`
  - `Writeback`
  - `EscalationPack`
- manifest vs StateLog authority recommendation

## Out of Scope

- heavy runtime implementation
- watchers / schedulers / databases
- full plugin automation
- direct executor access to `.gm_bus`
- governance-layer implementation details inside SkillForge
