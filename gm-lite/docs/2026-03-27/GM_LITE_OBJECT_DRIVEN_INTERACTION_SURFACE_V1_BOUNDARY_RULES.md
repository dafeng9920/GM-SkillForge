# GM_LITE_OBJECT_DRIVEN_INTERACTION_SURFACE_V1_BOUNDARY_RULES

## Boundary

This is an interaction-surface implementation line.

It must:

- make frozen objects visible and actionable
- reduce operator friction
- keep human control explicit

It must not:

- invent new governance authority
- hide process behind automatic drift
- expand into heavy runtime center behavior
- replace bridge / writeback protocol with ad hoc UI state

## Hard Rules

1. Every visible action must map to a known object or control point.
2. Every visible next action must map to `NextAction`, not free-form text only.
3. Every visible defect path must map to defect / repair / re-entry objects.
4. Plugin UI may expose governance-relevant information, but may not become final governance authority.
