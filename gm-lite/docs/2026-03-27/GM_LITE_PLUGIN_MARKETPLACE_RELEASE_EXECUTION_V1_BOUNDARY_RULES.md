# GM LITE Plugin Marketplace Release Execution v1 Boundary Rules

## In Scope
- Publisher 注册状态确认
- Marketplace 管理入口与发布身份确认
- 发布所需 PAT / 登录前提确认
- `.vsix` 发布执行路径

## Out Of Scope
- 再次修改插件代码
- 再次补齐 marketplace 资产
- 大规模文案或营销动作
- 非 VS Code Marketplace 平台

## 红线
- 不把未完成的账号/平台动作伪装成已完成
- 不以代码侧通过替代平台侧通过
- 不在 release execution 轮再插入新实现需求
