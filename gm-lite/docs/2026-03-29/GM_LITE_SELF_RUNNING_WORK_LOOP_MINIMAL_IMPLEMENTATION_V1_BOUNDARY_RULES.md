# GM-LITE Self Running Work Loop Minimal Implementation V1 Boundary Rules

## Fixed Constraint

Self-running behavior must remain:

- bounded
- visible
- interruptible
- auditable

## Must Not Become

- blind auto-runner
- heavy runtime center
- governance substitute
- generic remote executor

## Required Principle

The plugin may advance work automatically inside a narrow loop, but the human must still retain visible control at meaningful gates.
