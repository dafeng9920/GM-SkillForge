# GM-LITE Self Running Closure Patch V1 Boundary Rules

## Fixed Constraint

The patch must close the loop without turning `GM-LITE` into:

- a blind auto-runner
- a heavy runtime center
- a scheduler platform

## Required Outcome

- bounded automatic progression
- bounded automatic return-to-surface
- visible and interruptible loop closure

## Not Allowed

- hidden multi-step autonomy
- policy-heavy automation
- governance relocation into plugin
