# GM-LITE Surface Return Identity Patch V1 Boundary Rules

## Fixed Constraint

This patch must fix identity continuity, not widen the system into a broader workflow redesign.

## Required Outcome

- writeback carries work-surface return identity
- summary objects preserve that identity
- return logic works after task completion
- followback return entry appears whenever return identity is available

## Not Allowed

- hidden fallback hacks
- active-task-only assumptions
- broad runtime rewrites
