# GM-LITE Self Running Work Loop Minimal Implementation V1 Acceptance

## Module Pass Conditions

The module passes only if:

1. a bounded project loop can advance with materially reduced operator forwarding
2. automatic progression remains visible and controllable
3. writeback / followback return to the same working surface with lower manual cost
4. the operator only intervenes at meaningful gates rather than every step

## Failure Conditions

Fail or require changes if:

- automatic progression is hidden
- the loop still requires repeated manual forwarding
- operator burden does not materially drop
- the plugin drifts toward runtime-center behavior
