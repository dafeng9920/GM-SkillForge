# GM LITE Plugin Shell Seed Implementation v1 Scope

## 模块目标
- 实现 `GM-LITE` 第一版真正插件外壳的最小种子
- 宿主锁定为：
  - `VS Code Extension Shell`
- 目标不是完整产品，而是最小可安装、可打开、可承接状态与动作的插件壳

## 本轮唯一目标
1. 让插件壳真实存在
2. 让插件壳能读取 `GM-LITE` 当前状态
3. 让插件壳具备最小动作入口
4. 为手动转递消失的第一刀预留桥接挂点
