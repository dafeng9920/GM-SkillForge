# GM LITE Real Test Harness Minimal Implementation v1 Scope

## 模块目标
- 把真实测试体系从 preparation 推进到最小实现
- 让 `GM-LITE` 拥有真实可跑的测试命令、测试文件和测试报告输出
- 不追求完整平台，只先做最小可用内架

## 本轮唯一目标
1. 建立真实测试命令入口
2. 建立最小测试文件布局
3. 建立最小 sample replay / operational test
4. 建立 `json + md` 测试报告输出

## 完成定义
- 至少一条真实测试命令可跑
- 至少一组测试文件存在并可执行
- 至少一份 `json + md` 测试报告可产出
- `TI1-TI4` 三件套齐全
