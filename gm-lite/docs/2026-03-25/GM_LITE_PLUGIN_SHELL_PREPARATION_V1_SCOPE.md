# GM LITE Plugin Shell Preparation v1 Scope

## 模块目标
- 为 `GM-LITE` 建立真正的插件外壳前置定义
- 明确第一版插件壳的宿主、最低能力和边界
- 明确“手动转递开始消失”的第一刀落点

## 当前定位
- 这不是目录壳、运行壳、文档壳
- 这是面向产品承载的 `插件外壳准备模块`
- 它服务于 `作战运行级 1`

## 本轮必须回答
1. 插件宿主先锁定为什么
2. 第一版插件壳最低能力是什么
3. 手动转递第一刀从哪里落
4. 当前明确不做什么

## 默认决策
- 第一版宿主默认锁定：
  - `VS Code Extension Shell`
- 原因：
  - 当前工作流就在 IDE 内
  - 最接近“本地可安装、可打开、可承接动作”的产品形态

## 第一版最低能力
- 插件入口
- 状态查看面板
- 当前 step / next step 可见
- 手动动作最小入口
- 为桥接壳预留：
  - task send hook
  - writeback receive hook

## 本轮不做
- 不做复杂美化 UI
- 不做完整自动派单
- 不做完整多模型桥接
- 不做市场发布包装细节
- 不进入重型实现层

## 完成定义
- 四张任务卡三件套齐全
- 宿主、能力、第一刀桥接点、排除项全部冻结
- 后续可直接进入插件壳 seed implementation
