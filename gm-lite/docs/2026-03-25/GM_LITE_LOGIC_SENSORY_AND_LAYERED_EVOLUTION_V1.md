# GM LITE Logic Sensory And Layered Evolution v1

## 核心结论
- 这批增强不改变 `GM-LITE` 主线
- 它们的作用是：把现有的物理支柱继续硬化成 `逻辑感官系统`
- 当前可直接吸收的部分：
  - `M6` 三极分支
  - `human_in_the_loop CLI`
  - `Offset Compensation`
  - `Logic Fuse`
  - `DAG / hash chain`
- 当前后置的部分：
  - `M5` 全局建议层
  - 本地 `7B` 副官的完整接入
  - 贝叶斯三次采样封印

## 三大支柱的数学硬化

### 空间感
- 当前已吸收：
  - 语义锚点
  - 原始意图 / noun anchors 的向量对齐接口
- 后续增强：
  - 仿射矩阵
  - 视觉坐标锚点

### 时间感
- 当前已吸收：
  - `DAG`
  - `topological_sort`
  - `checkpoint hash chain`
- 作用：
  - 形成不可逆逻辑时间轴

### 价值感
- 当前已吸收：
  - 语义分值阈值
  - 红线拦截
  - 资产不合格即不准封印
- 后续增强：
  - `Bayesian consistency sampling`

## M6 的逻辑感官系统
- `semantic_score(a, b)`：向量化语义审计接口
- `三极分支`：
  - Green
  - Yellow
  - Red
- `CLI 火控协议`：
  - `Force Pass`
  - `Retry`
  - `Abort`
- `Offset Compensation`：
  - Retry 必须携带偏差反馈
- `Logic Fuse`：
  - 最多 3 次
  - 超限冻结并升级主控官

## Layered Defense：三层防火墙

### L1 物理层
- 路径
- 文件
- JSON 读写
- manifest / blueprint / seal
- 这一层即使上层崩了也必须稳定存在

### L2 过滤层
- 本地 20MB 语义模型
- `M6` 语义评分
- CLI 决策
- 红线与保险丝

### L3 进化层
- 本地 7B 副官
- 全局建议
- 冲突检测
- 摘要更新
- 资产复用建议

## M5 预审反馈的定位
- `M5` 不是当前最小闭环的必须件
- 但它是后续高价值增强层
- 它未来可输出：
  - 冲突预警
  - 资产复用建议
  - 架构债提醒

## 本地 7B 副官的定位
- 它适合承担：
  - 意图压缩
  - 冲突检测
  - 摘要更新
  - 低成本脏活
- 它不应替代：
  - Python Executor
  - Controller Arbiter
