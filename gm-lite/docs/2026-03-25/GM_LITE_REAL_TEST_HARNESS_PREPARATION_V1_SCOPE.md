# GM LITE Real Test Harness Preparation v1 Scope

## 模块目标
- 为 `GM-LITE` 建立真实测试体系的前置边界
- 冻结测试对象、测试命令、测试文件、测试报告的最小标准
- 为后续 minimal implementation 铸造内架

## 本轮唯一目标
1. 明确当前要测什么
2. 明确测试命令入口长什么样
3. 明确测试文件应放在哪里
4. 明确测试报告如何输出
5. 明确当前不测什么

## 当前定位
- 这不是测试实现层
- 这是测试体系 preparation
- 目标是先锁边界，再做内架

## 完成定义
- `TH1-TH4` 三件套齐全
- 测试边界、命令、文件布局、报告口径全部冻结
