# GM-LITE Human Control Flow Integration Patch V1 Boundary Rules

## Fixed Constraint

This patch must connect control primitives into flow execution without expanding `GM-LITE` into a heavy orchestration center.

## Required Outcome

- control points can stop or redirect flow explicitly
- blocked / paused / resumed effects are visible
- human action remains explicit and operator-driven

## Not Allowed

- hidden auto-continue logic
- policy-heavy scheduling
- governance decisions inside flow runtime
