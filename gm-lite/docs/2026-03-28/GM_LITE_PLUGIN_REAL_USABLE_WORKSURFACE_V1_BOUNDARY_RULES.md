# GM-LITE Plugin Real Usable Worksurface V1 Boundary Rules

## Fixed Role

`GM-LITE` remains:

- upstream task-reality layer
- lightweight access / adaptation entry
- execution bridge layer
- operator-facing working surface

## Must Not Drift Into

- status-only shell
- blind auto-runner
- heavy runtime center
- final governance layer
- full chat replacement

## Required Product Direction

The plugin must continue moving toward:

- document in
- automation flow advances
- code out
- process visible
- human-controllable flow

## Hard Constraints

- no hidden autonomous escalation
- no final trust judgment inside plugin
- no heavy scheduling layer
- no replacement of `superpowers` or `SkillForge`

## UX Constraint

A visible surface is not sufficient unless it also reduces real operator hops.
