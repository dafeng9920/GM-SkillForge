# GM-LITE Automatic Control Trigger Minimal Implementation V1 Boundary Rules

## Fixed Constraint

Automatic triggering must remain:

- narrow
- rule-driven
- visible
- operator-auditable

## Must Not Become

- policy-heavy automation center
- hidden autonomous planner
- governance substitute
- scheduler expansion

## Required Principle

Automatic trigger exists only to surface and activate already-defined control points in live flow.
