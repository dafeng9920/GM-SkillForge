# GM-LITE Plugin Real Usable Worksurface V1 Scope

## Module

- `gm_lite_plugin_real_usable_worksurface_v1`

## Intent

Make `GM-LITE` feel like a real daily working surface instead of a merely validated plugin surface.

## Primary Goal

Reduce operator labor in a real project loop by shortening the path between:

- task artifact
- visible status
- visible next action
- explicit human control
- result / followback visibility

## In Scope

- work-surface-first interaction tightening
- fewer command-palette jumps
- clearer run / blockage / next-action visibility
- action paths for continue / pause / redirect / resume
- real project loop usability validation

## Out of Scope

- full chat-clone interface
- heavy scheduler / runtime-center behavior
- broad upstream vault implementation
- final governance relocation into plugin
- marketplace / publish work

## Success Test

This cut succeeds only if the plugin starts saving real operator effort during a real project loop.
