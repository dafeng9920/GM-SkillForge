# GM-LITE Plugin Real Usable Worksurface V1 Acceptance

## Module Pass Conditions

The module passes only if:

1. the plugin can be used as a daily work surface with reduced manual hops
2. current task / current run / blockage / next action are clearer in the same working surface
3. at least one real project loop shows explicit human control with lower friction
4. the plugin is measurably less shell-like and more work-surface-like

## Failure Conditions

Fail or require changes if:

- the plugin is still primarily command-palette-driven
- visible state remains mostly passive and non-actionable
- human control is nominal but not practical
- operator still needs repeated manual jumps to inspect and continue work
