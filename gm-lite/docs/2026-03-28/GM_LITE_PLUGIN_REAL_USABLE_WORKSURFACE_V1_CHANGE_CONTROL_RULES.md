# GM-LITE Plugin Real Usable Worksurface V1 Change Control Rules

## Allowed

- surface hardening
- interaction tightening
- visible action improvements
- reduced hop count
- explicit control path improvements

## Not Allowed

- broad architecture rewrite
- chat-clone expansion
- runtime-center expansion
- governance relocation
- upstream knowledge-layer implementation creep

## Review Standard

Prefer narrow changes that improve actual usability over broad conceptual expansion.
