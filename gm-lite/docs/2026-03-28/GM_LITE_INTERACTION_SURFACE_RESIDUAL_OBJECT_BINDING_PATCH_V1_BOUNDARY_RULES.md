# GM_LITE_INTERACTION_SURFACE_RESIDUAL_OBJECT_BINDING_PATCH_V1_BOUNDARY_RULES

## Boundary

This is a narrow repair line.

It must:

- patch residual text-shell behavior
- complete missing object bindings
- preserve current plugin boundary

It must not:

- redesign the whole plugin
- invent new protocol families
- move governance into the plugin
- add speculative runtime behaviors

## Hard Rules

1. Every new visible element must map to an existing frozen object.
2. This line may improve visibility and usability, but may not add heavy free-form UI state.
3. Residual text output is allowed only as support context, not as the primary interaction model.
